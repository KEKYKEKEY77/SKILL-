# Codex 技能介绍中文简化工具

一键将已安装 Codex 技能的介绍替换为简洁中文，方便在技能列表中快速识别。适用于 Windows PowerShell。

## 使用

1. 下载本仓库全部文件到同一文件夹。
2. 双击 `双击修改技能介绍.cmd`。
3. 脚本会扫描当前用户的 Codex 技能目录、插件缓存技能目录和 Skills Manager 技能目录。
4. 修改前的文件会保存在技能目录中的 `backups` 文件夹，可用于恢复。

也可以在 PowerShell 中直接运行：

```powershell
.\修改技能介绍.ps1
```

## 文件

- `修改技能介绍.ps1`：扫描并更新技能介绍，自动备份被修改文件。
- `双击修改技能介绍.cmd`：双击启动脚本。
- `descriptions.json`：技能名称与简体中文介绍映射，可自行调整。
- `使用说明.txt`：中文使用说明。

脚本只更新映射表中有对应条目的技能描述；未匹配的技能会跳过。
